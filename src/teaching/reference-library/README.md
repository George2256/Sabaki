# 讲解结构样例

24 个片段来自 Go Game Guru 发布的李世石对 AlphaGo 第一局评注，评注者为 An
Younggil（安永吉）八段。原始带变化的棋谱保存在
`test/resources/teaching/lee-alphago-1.sgf`。

来源：<https://github.com/gogameguru/commented-go-games/blob/master/2016/05/20160309-Lee-Sedol-vs-AlphaGo-Commentary-An-Younggil.sgf>

`patterns.json`
是本项目重新撰写的中文教学结构摘要，不是原文翻译，也不是已由 KataGo 认可的标准答案。每条记录保留原始手数、评注者、来源与验证范围。模型只会取得少量匹配的结构提示，不会把这些历史棋例的结论当作当前局面的事实。

[LICENSE](LICENSE)。保留 Go Game
Guru 与评注者署名；改编部分为本项目的中文结构摘要。该许可适用于这些资料，不改变项目程序代码的 MIT 许可。商业使用前应替换为自有或获得相应授权的样例。原始来源也保留在应用的分析证据面板中。

这是初始参考集，集中于一盘职业棋局，不代表低段学员的完整教学需求，也未经过独立教师验收。后续应补充不同棋力的授权复盘，并对错误原因、反驳变化和练习问题进行教师评分；不要用同一批参考样例兼作质量验收的唯一答案。
